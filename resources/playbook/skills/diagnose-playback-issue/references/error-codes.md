# Playback error codes

| Code | Meaning | Fix |
|---|---|---|
| SF-PLAY-0042 | Adaptive bitrate fell back to SD because sustained bandwidth stayed under 5 Mbps. | Move the device closer to the router or use Ethernet; pause other downloads; set playback quality to Auto. |
| SF-PLAY-0117 | DRM license renewal failed in the browser. | Update the browser, disable extensions that block scripts, make sure hardware acceleration is on, then reload. |
| SF-PLAY-0203 | The mobile app's cached manifest is stale after an app update. | Force-quit the app, sign out and back in; if it persists, clear the app cache or reinstall. |
| SF-PLAY-0310 | Title not licensed for the current region. | The customer is travelling or using a VPN; disconnect the VPN or wait until home. |
| SF-PLAY-0505 | Too many concurrent streams for the plan. | Stop another device or upgrade the plan. |
