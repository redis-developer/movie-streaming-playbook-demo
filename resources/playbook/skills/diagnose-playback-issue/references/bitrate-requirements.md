# Bandwidth requirements by quality

| Quality | Minimum sustained bandwidth | Plans |
|---|---|---|
| SD (480p) | 3 Mbps | Basic, Standard, Premium |
| HD (720p/1080p) | 5 Mbps | Standard, Premium |
| 4K HDR | 15 Mbps | Premium only |

If the measured bandwidth is below the requirement for the quality the plan allows,
the player will step down automatically. Recommend the customer run a speed test on
the same device, move closer to the router or use a wired connection, and set the
quality to Auto rather than forcing a high value.
